# TaskManagerEffectiveTrial

Тестовое iOS-приложение на UIKit для ведения списка задач.

## Описание

Приложение содержит список задач с возможностью управления задачами:

- отображение названия, описания, даты создания и статуса задачи;
- добавление новых задач;
- редактирование существующих задач;
- удаление задач;
- поиск по списку;
- отметка задачи как выполненной или невыполненной.

При первом запуске приложение загружает список задач из `https://dummyjson.com/todos`. После загрузки данные сохраняются в CoreData и доступны при следующих запусках.

## Архитектура

Проект разделен на несколько слоев:

- `Modules` - экраны списка задач и редактирования;
- `View` - отображение интерфейса и обработка действий пользователя;
- `Interactor` - бизнес-логика и операции с задачами;
- `Presenter` - подготовка данных для отображения;
- `Router` - навигация и сборка модулей;
- `Core` - работа с сетью, CoreData, репозиторием и зависимостями.

## Возможности

- Загрузка задач из API при первом запуске.
- Сохранение задач между запусками приложения.
- Создание новой задачи.
- Редактирование названия и описания задачи.
- Удаление задачи через контекстное меню.
- Поиск задач по названию.
- Переключение статуса выполнения.
- Выполнение операций с данными в фоновом потоке.
- Unit-тесты для основных компонентов приложения.
